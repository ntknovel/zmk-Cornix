Cornix ZMK STENO Quick Presets v1.6.1
==================================

변경사항
- 퀵 약어 4개 삼중모음 입력을 12개 단일모음 입력 M0~M11로 교체
- 구서룡/사구구/피피쿵/스타라이트/유안나/유혜나/케이지/마이스터/
  일렉트리스/실험체/W 시/A 시 프리셋 적용
- ZMK Keymap Editor Macros 화면에 quick_0~quick_11 노출
- config/steno_quick_text.tsv의 출력 텍스트만 고쳐 재생성 가능
- v1.5.1 오른손 peripheral/settings_reset 하드닝 유지

적용
1. v1.5.1이 이미 적용되었다면 PATCH_ONLY ZIP을 저장소 루트에 덮어씁니다.
2. 그 외에는 UPLOAD ZIP을 저장소 루트에 덮어씁니다.
3. python3 tools/validate_package.py .
4. git add -A
5. git commit -m "Add 12 editable Cornix STENO quick presets"
6. git push
7. GitHub Actions에서 left/right/settings_reset 모두 성공한 뒤 UF2를 사용합니다.
